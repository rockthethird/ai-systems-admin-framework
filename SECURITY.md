# Security Policy

## Reporting Security Issues

**DO NOT** open public GitHub issues for security vulnerabilities.

Instead, please report security issues by emailing [security@example.com](mailto:security@example.com) with:

1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested fix (if you have one)

**Please allow 90 days for us to address the issue before public disclosure.**

## Security Review

All contributions undergo security review for:

- Least privilege enforcement
- Attack vector coverage
- Audit logging completeness
- Threat model adequacy

## Supported Versions

Only the latest major version receives security updates.

## Security Best Practices

1. **SSH Keys:** Rotate keys regularly, store securely
2. **Audit Logs:** Monitor and archive regularly
3. **Updates:** Keep AI agent framework updated
4. **Testing:** Run validation suite after any changes
5. **Network:** Restrict SSH access to trusted IPs only
